# chetan-portfolio

Personal portfolio website — [https://chetan7171.github.io/chetan-portfolio](https://chetan7171.github.io/chetan-portfolio)

## Tech

- Vanilla HTML + CSS (no frameworks, no build step)
- Auto-deployed to **GitHub Pages** via GitHub Actions on every push to `main`

## Local preview

```bash
# Just open in browser — no server needed
open index.html
```

## Customize

Edit `index.html` directly:
- Update your name, title, summary in the **Hero** and **About** sections
- Add/remove skill tags in the **Skills** section
- Add new projects in the **Projects** section
- Update LinkedIn/email links in the **Contact** section
